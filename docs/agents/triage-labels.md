# Triage labels

Use these tracker labels when an upstream skill names a triage role.

| Upstream role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer evaluation. |
| `needs-info` | `needs-info` | Needs more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Has enough specification for agent implementation. |
| `ready-for-human` | `ready-for-human` | Needs human implementation. |
| `wontfix` | `wontfix` | Will not be implemented. |

A readiness label does not satisfy a dependency or product release gate. Use the
[issue tracker](issue-tracker.md) to decide execution readiness.
