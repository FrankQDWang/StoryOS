1. 档案正文只写三种事：程立亲身在场经历的事；别人当面或在电话里告诉程立的事；程立自己做过、说过的事。

3. 拿不准程立知不知道的事，不要写进正文，单独列在【拿不准】里，并说明为什么拿不准。
4. 正文暗示程立自己心里清楚、但正文还没有写明的事（程立瞒着没说的事），列在【待作者补充】里。只写问题，不要猜答案。
5. 不要编正文里没有的事实。时间截止到第七章结尾的那个夜里。
