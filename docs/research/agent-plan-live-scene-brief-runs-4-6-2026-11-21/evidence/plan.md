The run is no trial that compares models or prompts, and it does not assert that the model obeys the text.

The release package of `python3 scripts/package-release.py` on that clean commit: the packaged Server with `STORYOS_WORKER=0`, `STORYOS_MODEL_DESTINATION=volcengine_agent_plan`, and `STORYOS_SKILLS_DIR` set to the `skill-packages` of the release package (`conflict-check`, `local-revision`, `scene-brief`), and one continuous packaged Worker. The same process environments as the first run. No embedding destination and no Exa key. The run never reads an env file or a key.

- **AgentRuns:** 3 (with Runs 1 to 3 and the first Runs 4 and 5, 8 in total; the limit of the ticket is 8). The same three author messages:
  - Run 4: "接下来写林舟坐老周的船过河、去省城找姐姐这一场。先对一下思路再写。" The record gives: `load_skill` for `scene-brief` or not, the brief and the question, and the number of Proposals.

  - Run 6, the same Conversation: "再写下一场：林舟到了省城的码头，没有找到来接他的人。" The record gives a brief or a Proposal at once.
- **Planned number of requests: Run 4: 5, Run 5: 4, Run 6: 4; 13 in total.** Each model request counts, also the request after the label "The input of this author request changed". The steps of Run 4: `load_skill`, one read step, the final answer, and one spare step, with one more step for a second read. The steps of Runs 5 and 6: `propose_edit` or a read, the request after the label, the final answer, and one spare step. The request guard of the database refuses the claim of a request above the number of its Run and of a 14th request in total.
- **Planned number of reported input tokens: Run 4: 45,000, Run 5: 45,000, Run 6: 50,000; 140,000 in total.** A sum above one of them stops the run. A request above 40,000 input tokens also stops it.
- **Raw evidence at a stop:** a stop also writes the wire payloads, the Model Attempts, the ToolCalls, the Run rows, and the guard log. This is the only change of the script.
- **Stop rule:** the script stops the Worker when the guard refuses a request, when a Run does not end 90 seconds after the planned number of its requests, or above one of the planned numbers. A stop is reported to the coordinator before any next request. Other stops: more author Runs than the plan, a Run that is not an author Run, a refused or cancelled Run, an Exa exchange, or an embedding request. The run stops the Worker before the Memory work of the Host is due.
