# 第一章 渡口

雨从傍晚下起，到天黑也没停。林舟把伞靠在候船棚的柱子上，伞面上的水顺着竹骨往下滴，在水泥地上积成一小摊。对岸的灯一盏一盏亮起来，最后一班渡船还拴在岸边，没有动。

老周坐在船头抽烟，烟头在雨里明一下，暗一下。他看见林舟，把烟往船帮上一按，说：“今天不开了。浪大。”

“我姐在对岸。”林舟说，“她说坐最后一班回来。”

“她要是真想回，下午那班就回了。”老周没抬头，用脚把缆绳往里拨了拨，“你回去吧，你妈一个人在家。”

林舟没动。她口袋里有一张折了四折的车票，是林雪上个月寄回来的，日期写着今天，车次后面画了一个圈。信封里没有信，只有这张票。她想过很多回这个圈是什么意思，想不出来，就不想了，只记住了日期。

候船棚里还有一个卖茶叶蛋的女人，炉子上的锅盖被热气顶得一跳一跳。女人看了林舟好几眼，终于开口：“你是林家的二丫头吧？你姐小时候常在这儿等你爸的船。”

林舟点点头。她爸的船十年前在这条江上翻了，那年林雪十四岁，她九岁。后来林雪每天放学都来渡口，一直坐到天黑，谁叫都不走。再后来林雪去了对岸的城里念书，就很少回来了。

林舟记得那几年。林雪不哭，也不说话，只把书包垫在长凳上坐着，看江上来来往往的船。有一回下大雪，母亲让林舟来叫她回家吃饭。林雪看了她一眼，说：“你先回去，我再等一班。”那天最后一班船靠了岸，下来的都是不认识的人。林雪站起来，拍掉身上的雪，跟她一起走回了家。路上两个人都没说话。

江上起了风，雨斜着打进棚里。老周起身收船灯，路过林舟身边时停了一下，把自己的旧雨衣扔在她旁边的长凳上。

“十点还有一班运货的，”他说，“不载人。我跟老钱说一声，他要是肯，就把你姐捎过来。”

林舟说了声谢谢。老周摆摆手，钻进船舱里去了。卖茶叶蛋的女人把炉子往里挪了挪，给她让出一块干的地方，又塞给她一个蛋，说不要钱。

林舟抬起头。对岸的码头上，有一个人影站在灯下，看不清脸，手里好像提着一个箱子。
