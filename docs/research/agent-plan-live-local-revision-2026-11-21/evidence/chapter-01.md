# 夜渡

天还没亮，林舟就到了渡口。老周的木船拴在桩上，船头挂着一盏防风灯。

老周微微点头，缓缓起身，轻轻地推开船舱的门，仿佛早就知道他会来。

林舟把两文钱放在船板上，说要去对岸找姐姐。老周没有收钱，只把缆绳解开了。

听到“对岸”两个字，老周的眼中闪过一丝慌乱，嘴角勾起一抹苦涩的弧度。

这不是一次普通的渡河，而是林舟第一次违背姐姐的嘱咐。

老周低声说了一句：“那边的人，回不来了。”这句话如同石子投入湖面，在林舟心里泛起层层涟漪。

船到河心，林舟摸了摸脖子上的怀表。表还停在四点十分。

然而，雾越来越浓，水越来越急，岸越来越远。

林舟心中涌起一股暖流，他终于明白，姐姐留下钥匙，是想让他自己做决定。

他不知道的是，命运的齿轮已经开始转动。
