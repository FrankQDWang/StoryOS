- **Purpose:** show the effect of the instructions of the package `local-revision` on the real Agent Plan route (`S10-EVD-002`). The run is no trial that compares models or prompts, and it does not assert that the model obeys the text.
- **Product:** `1764-local-revision` at `544727597ddd821446403fd633300be5518c7f5e` (tree `e9f016cf97115f5fb9fa04bbff09c030dba58d06`), on `stage10-author-voice` `e27a95fb` (mapping `v10`, Registration `fa24`, with the default rules for prose of #1761). The release package of `python3 scripts/package-release.py` on that clean commit: the packaged Server with `STORYOS_WORKER=0`, `STORYOS_MODEL_DESTINATION=volcengine_agent_plan`, and `STORYOS_SKILLS_DIR` set to `target/release-package/skill-packages`, and one continuous packaged Worker with `STORYOS_MODEL_DESTINATION=volcengine_agent_plan`. Each process environment has only the named variables, `PATH`, and `HOME`. No embedding destination and no Exa key. The run never reads an env file or a key.
- **Fixed inputs:** two new Projects (夜渡 A and 夜渡 B), each written through the public commands with the same Chapter 夜渡 of 10 Blocks and the same Project Instruction. 7 Blocks have a planted habit of the default rules (rules 1, 2, 3, 4, 5, 6, and 7). The Project Instruction has a sample passage that uses the contrast frame of rule 1 (不是……是……) on purpose, and Block 5 ("这不是一次普通的渡河，而是……") uses that device. The list of the planted habits is `planted.md` of the evidence tag.
- **AgentRuns:** 2 (the limit of the ticket is 4), each with the selected Skill `local-revision`, in a new Conversation:
  - Run A in Project A: "请修改这一章。" Expected: at most 5 changed Blocks in one Proposal.
  - Run B in Project B: "只改最明显的 2 处。" Expected: at most 2 changed Blocks. Project B is separate, so the open Proposal of Run A does not change the input of Run B.
- **Planned requests:** 6 (3 for each Run: `propose_edit`, `finish`, the answer). Automatic requests count. The Memory work of the Host is due only 30 minutes after a Run or 1 hour after a Chapter change, so the run ends and stops the Worker before it.
- **Expected reported input:** about 6,000 to 9,000 tokens for each request, about 45,000 in total.
- **Hard caps:** a database trigger of the disposable database refuses the claim of the 13th model request, of each Exa exchange, and of each embedding request. The run script stops the Worker at more than 12 requests or 120,000 input tokens in a Project, a request above 40,000 input tokens, a second author Run in a Project, a Run that is not an author Run, or a refused or cancelled Run.
- **Rehearsal:** done on `host_fake` on the same head: 2 author Runs, 4 fake requests, no other Run.
