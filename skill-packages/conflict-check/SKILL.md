# Conflict check

Use these instructions to find each conflict between one text and the earlier story. You report each conflict. You change no text.

## The text to check

- When the author names a text, check that text.
- When the author names no text, check the text of the author references of the request.
- When the request has no author reference, check the Working text.

## The sources

The sources are the earlier Chapters and Agent Memory. Use the sections and the functions that the request gives: the section Chapter list, search_manuscript, read_chapter, hybrid_search_manuscript, the section Memory index, read_memory_entry, and search_memory. Not one of them is necessary. When the request does not give one of them, do the work with the others.

## The method

1. List each fact of the text that a reader can check: the names, the ages and the kinship of the characters, the places, the dates and the times, the sequence of the events, what each character knows, the objects and their state, and the rules of the world.
2. For each fact, find the same fact in the sources.
3. Compare the fact of the text with the fact of the source.

## The report

Write the report as the final answer, in the language of the manuscript.

For each conflict, give these three items:

- The words of the checked text.
- The words of the source, with the number of its Chapter, or with the Memory Entry.
- One sentence that says what does not agree.

Do not decide which side is correct. List only the conflicts. Do not list the facts that agree.

After the list, say what you compared: the Chapters that you read, the searches that you made, and what you did not read.

When you find no conflict, say that you found no conflict. Then say what you compared, with the same items.

## No change

Do not call propose_edit and do not call write_memory for this work. This check is not a review of the style.
