# 对白写法规范

写或改写小说对白时，遵守下面的规则。

## 规则

1. **引号**：所有对白一律使用直角引号「」，引语中的引语使用『』。不要使用“”或""。
2. **说话人标签**：标签只用「说」「问」「答」三个动词，放在对白之后，例如：「我明天走。」林舟说。不要用「咆哮道」「冷笑道」这类修饰性动词。
3. **一句一事**：一句对白只表达一个意图。人物想说两件事时，拆成两句，中间插入一个动作或停顿。
4. **潜台词**：人物不直接说出自己的感受。用动作、回避和答非所问来表现情绪。
5. **口吻区分**：每个人物的句子长度和用词不同。读者遮住标签后，仍能分辨是谁在说话。
6. **方言与口头禅**：一个人物最多一个口头禅，一场戏最多出现一次。

## 做法

1. 先确认场景里有哪些人物，以及每个人物在这场戏里想要什么。
2. 写出对白，然后逐条检查上面的规则。
3. 需要参考时，阅读 `references/examples.md` 中的改写前后对比。

在回答中给出修改后的对白时，同时用一句话说明改动了哪几条规则。
