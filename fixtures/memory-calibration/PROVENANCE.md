# Provenance of the Memory calibration sample

The live calibration run of S7-D7 (ADR 0094 section 8) uses this directory as its sample manuscript. The text of each Chapter file is test data.

- The text is original. It was written for this repository on 2026-11-17 for the calibration, in the Simplified Chinese of a present-day novel.
- It has no text of another work, and it does not copy, translate, or adapt another work.
- It names no real person. Each name, the town 青溪镇, the teahouse 临水茶馆, the paper 《青溪小报》, and each company are fiction.
- The manuscript of the author is not a sample (the author approved the original sample on 2026-11-16).
- Thus the text can be in a request record on a public evidence tag.
