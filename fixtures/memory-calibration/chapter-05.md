# 第五章 开

知遥决定把茶馆开一个星期。

她跟公司请了两周的假，理由是家里的事情还没处理完。江屿在微信上发了一串问号，说甲方那边催得很急，又说她要是不回来，那个商场的方案就要交给别人了。

“交给别人吧。”她回。

江屿过了很久才回了一个字：“行。”

她跟顾青禾说要开门的时候，顾青禾正在后院洗茶碗。后院不大，地上铺着青砖，墙角有一口老井，井口盖着一块圆形的青石板，石板上压着一个破瓦盆，种着一盆葱。爷爷说这口井早就不用了，盖起来是怕小孩掉下去。

“开一个星期？”顾青禾把茶碗放进竹篮里，“开了做什么？”

“我想看看。”知遥说，“看看茶馆开着是什么样子。我好久没见过了。”

顾青禾看了她一会儿，擦了擦手：“那得先去买茶叶。家里的龙井只剩半斤了。”

她们花了两天准备。顾青禾去镇上的茶叶店进了龙井、碧螺春和菊花，知遥把墙上的茶牌一块一块取下来，用湿布擦干净，重新用粉笔写上价钱。她犹豫了很久要不要涨价，最后还是按爷爷原来的价钱写：龙井八块，碧螺春六块，菊花四块，老白茶十块。

“老白茶十块，太便宜了。”顾青禾说。

“爷爷写的就是十块。”

“那是三年前的价钱。”顾青禾说，“算了，开一个星期，随你。”

知遥注意到，顾青禾自己泡的一直是老白茶。她问为什么，顾青禾说：“冬天喝老白茶，暖胃。别的季节，我什么都不喝，喝白开水。”

“现在是春天啊。”

顾青禾愣了一下，看了看自己的杯子，好像才发现：“习惯了。”

开门那天是星期一。

早上六点，知遥就起来了。她把门板一块一块卸下来，靠在墙边。春天的阳光从门口照进来，落在擦得发亮的方桌上，茶馆里一下子亮了。她把那台红灯收音机打开，调到镇上的广播台，正在放越剧。

第一个客人是七点半来的。

是一个六十多岁的老先生，穿一件中山装，拄着一根手杖，在门口站了一会儿，看着招牌，然后走进来，在靠窗那张桌子边坐下。

“一杯龙井。”他说。

知遥给他泡了茶，端过去。老先生喝了一口，点点头：“还是这个味道。”

“您以前常来？”

“三十年了。”老先生说，“你爷爷走了以后，我以为这里不开了。”

“我只开一个星期。”

老先生看了她一眼，没说什么，慢慢喝着茶，看着窗外的青溪。

那天来了十一个客人，大多是老街坊，有的坐一会儿就走，有的一坐一上午。许阿婆的青团卖得特别好，中午就卖完了。

第二天来了十七个，第三天来了二十二个。有几个年轻人，是从县城开车过来的，说在网上看到有人发了临水茶馆开门的照片。他们拍了很多照片，拍招牌，拍茶牌，拍那台红灯收音机，拍窗外的老桥。

知遥站在柜台后面，看着满屋子的人，忽然觉得有点恍惚。小时候她就是坐在这个柜台后面，看着爷爷给客人倒茶。那时候她觉得茶馆很大，人很多，声音很吵。现在她站在爷爷的位置上，才发现茶馆其实很小，八张桌子，坐满了也就三十来个人。

第三天下午，茶馆里来了一对年轻夫妻，抱着一个一岁多的孩子。他们在靠门的桌子边坐下，点了两杯碧螺春。孩子不肯坐，一直伸着手要去够桌上的茶碗，妈妈只好抱着他在茶馆里走来走去。

孩子看见了柜台上那台红灯收音机，眼睛一下子亮了，伸手去拍。收音机正在放越剧，被他一拍，声音忽然大了，咿咿呀呀地唱起来，满屋子的人都笑了。

“对不起，对不起。”妈妈红着脸把孩子抱开。

“没事。”知遥说，“这台收音机比我年纪还大，经得起拍。”

她把音量调小，孩子还盯着收音机看，嘴里“啊啊”地叫。知遥从柜台底下找出一个旧的拨浪鼓，是很多年前不知道哪个客人落下的，爷爷一直收着。她把拨浪鼓递给孩子，孩子抓着摇了两下，咯咯地笑了。

那对夫妻走的时候，说他们是从县城来的，小时候在青溪长大，后来家里搬走了。

“我小时候跟我爷爷来这里喝过茶。”丈夫说，“他喝茶，我吃瓜子。那时候我觉得这里好大。”

“现在呢？”

“现在觉得小了。”他看了看四周，“可是还是那个味道。”

他们走了以后，知遥坐在门槛上，看着许阿婆收摊。许阿婆把竹匾里剩下的几个青团用竹叶包好，塞进一个布袋子里。

“阿婆，今天卖得好吗？”

“好。”许阿婆笑得眼睛都眯起来了，“比你爷爷在的时候还好。那些年轻人，一买就是五六个，说要带回去给同事尝尝。”

她把布袋子挂在车把上，又从里面拿出一个青团递给知遥：“这个是咸的，雪菜肉丝的，我自己吃的，给你尝尝。”

知遥咬了一口，雪菜很咸，肉丝很香，糯米皮软软的，粘牙。

“好吃。”

“你爷爷也爱吃咸的。”许阿婆说，“他说甜的是给小孩吃的，大人要吃咸的。”

许阿婆推着车走了，车轮在石板路上咕噜咕噜地响。知遥把剩下的半个青团吃完，在门槛上又坐了一会儿。对岸的新楼亮起了灯，一扇一扇的，像是一格一格的格子。

顾青禾在里面喊她：“进来吃饭，外面起风了。”

第四天，陆砚来送藤椅。

藤椅修好了，椅面是新编的藤条，颜色比原来浅一些，椅腿和横档都重新上了榫，坐上去稳稳当当，一点声音都没有。

“藤条的颜色过一两年就深了。”陆砚说，“坐的人多了，手摸多了，就和原来一样了。”

知遥把藤椅放回柜台后面原来的位置，坐上去试了试，很舒服。

“多少钱？”

“说了不要。”

“那你在这里喝茶，以后都不要钱。”

陆砚笑了一下。他很少笑，笑起来的时候眼角有两道细细的纹。

他在茶馆里待了一会儿，没有坐，一直在看屋顶。茶馆是两层的木结构，一楼的屋顶就是二楼的地板，几根粗大的木梁横在头顶，漆成了深红色，上面挂着几盏老式的吊灯。

“怎么了？”知遥问。

陆砚没回答，搬了一张凳子过来，站上去，伸手摸了摸正中间那根最粗的梁。他摸得很仔细，从一头摸到另一头，在靠近柜台那一端停住了。

“你过来看。”

知遥也站上凳子。陆砚用手指着梁的侧面，那里有一道裂缝，被红漆盖着，不仔细看看不出来。裂缝有一尺多长，最宽的地方能塞进一枚硬币。

“这是主梁。”陆砚说，“裂了有些年头了，最近又开大了。你看这里，漆是新裂的。”

“危险吗？”

“现在还撑得住。”陆砚从凳子上下来，“可是这房子在河边，潮气大，木头会继续裂。要是碰上大风大雨，梁一受力，就说不准了。”

“能修吗？”

“能加固。”陆砚说，“在梁下面加两根托木，再用铁箍把裂缝箍起来。不用换梁，换梁要把整个二楼拆了。”

“要多久？”

“三四天。”陆砚说，“不过得关门做。”

知遥想了想，说：“那等这个星期开完。”

陆砚点点头，又抬头看了一眼那根梁，看了很久。

第七天是星期天，来的人最多，二十八个。傍晚最后一个客人走了以后，知遥把门板一块一块装回去，顾青禾在后面洗茶碗，水声哗哗的。

一个星期，一共卖了一百三十多杯茶，收了一千零几十块钱。扣掉茶叶和水电，几乎没有剩下什么。

知遥把账记在爷爷的最后一本账本上，接着三月那一笔往下写。她的字和爷爷的字挨在一起，一个歪，一个正，看起来有点奇怪。

她在这一页的边上，学着爷爷的样子，写了一行小字：“今日晴，客二十八人。梁有裂。”
