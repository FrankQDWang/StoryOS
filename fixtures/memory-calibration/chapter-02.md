# 第二章 箱

葬礼办得很简单。

镇上来了不少人，大多是上了年纪的老街坊，在灵堂前鞠三个躬，往功德箱里塞一个白信封，然后站在门外的屋檐下小声说话。说的都是爷爷的事：哪一年他把茶馆的门板拆下来给发大水的人家搭床，哪一年他赊了半年的茶钱给镇上的穷学生，哪一年他和人吵架，吵到最后自己先笑了。

知遥站在灵堂一侧，听着这些她从来不知道的事情，觉得爷爷好像是一个陌生人。

赵德明是被人扶着来的。他拄着一根拐杖，在灵前站了很久，嘴里念念有词，谁也听不清他说了什么。最后他把手放在棺木上，拍了两下，像是拍一个老朋友的肩膀。

知遥过去扶他。他抬起头看了她半天，才说：“你是遥遥。”

“赵爷爷。”

“长这么大了。”赵德明说，“你爷爷总念叨你。”

她不知道该怎么回答。爷爷念叨她，可是她这十八年里只在春节的时候打过几个电话，每次都说不到五分钟。

赵德明握着她的手，握得很紧。他的手很粗糙，掌心全是老茧，是几十年撑船撑出来的。他好像还想说什么，可是旁边的人来扶他坐下，他就没再开口。

出殡的时候，天阴着，没有下雨。

爷爷葬在镇子西边的山坡上，那里有一片老坟地，种着一排柏树。送葬的队伍从临水街出发，过了老桥，沿着河边的小路往西走。走在最前面的是两个吹唢呐的老人，唢呐的声音又尖又长，在河面上传得很远。

知遥捧着爷爷的遗像走在父亲后面。遗像是前年拍的，爷爷穿着那件灰色的开衫，坐在藤椅上，背后是茶馆的柜台。照片里他没有笑，可是眼睛是弯的，像是刚听完一个好笑的故事，正在忍着。

路上有人家在门口摆了一张小桌子，桌上放着一碗清水、一炷香。队伍经过的时候，那家的人就站在门口鞠一个躬。知遥数了数，一路上一共有十四张这样的小桌子。

“都是受过你爷爷照顾的人家。”顾青禾走在她旁边，小声说。

山坡上的风很大，吹得柏树哗哗响。下葬的时候，父亲让知遥撒第一把土。她蹲下去，抓了一把土，土是湿的，凉凉的，从指缝里漏下去，落在棺木上，发出很轻的一声。

她站起来的时候，看见顾青禾站在人群的最后面，没有往前挤，只是远远地看着。她没有哭，手里攥着一块手帕，攥得很紧。

回去的路上，太阳出来了一会儿，又躲进云里。知遥走在队伍的最后，回头看了一眼山坡，那排柏树在风里一起摇着，像是在送人。

葬礼结束后，父亲在镇上的饭店订了两桌，请帮忙的人吃饭。饭吃到一半，他就把知遥叫到了外面。

饭店门口有一棵老樟树，树下放着两张塑料椅子。沈明川点了一根烟，抽了两口，才说：“茶馆的事，我想跟你商量一下。”

“你想卖。”知遥说。

沈明川没想到她这么直接，愣了一下，然后点点头：“临水街要开发，有个公司在谈整条街的收购。价钱还可以。”

“爷爷刚走。”

“我知道。”沈明川把烟灰弹在地上，“可是房子放在那里也是烂。你在上海，我在杭州，谁来管？青禾年纪也大了。”

“你签了什么没有？”

“没有。”沈明川说，“什么都没签。我说了，这是跟你商量。”

知遥看着他。父亲说话的时候没看她的眼睛，而是看着樟树的树干。她小时候听妈妈说过，父亲撒谎的时候就是这样，眼睛总要找个别的地方落。可是妈妈已经走了十二年了，她也不确定这句话还算不算数。

“我想先把爷爷的东西收拾一下。”她说。

“行。”沈明川把烟掐了，“你收拾，我过几天再来。”

第二天，知遥开始收拾茶馆。

顾青禾来帮忙，两个人从楼上收拾到楼下。爷爷的东西不多，几件换洗衣服，一双布鞋，一个装着老花镜和针线的铁皮盒子，一摞旧报纸，还有一抽屉的票据，有电费单、水费单，最早的一张是一九九二年的。

“你爷爷什么都留着。”顾青禾说，“连买茶叶的收条都留着。”

“青禾阿姨，你帮我看看哪些要留，哪些可以扔。”

顾青禾翻了翻那些票据，说：“都留着吧，你以后慢慢看。”

她们收拾到柜台的时候，已经是下午了。柜台是一整块老榆木做的，很重，台面上有一道一道的刻痕，是几十年茶碗压出来的。柜台下面有三个抽屉和一个柜门。抽屉里是茶叶罐、杯盖、一把旧算盘，柜门里塞满了杂物：几捆麻绳，一个坏掉的暖水瓶，一叠蓝底白花的桌布。

知遥把这些东西一样一样拿出来，最后在柜子的最深处摸到了一个硬的东西。

她把它拖出来，是一只木箱子。

箱子不大，比鞋盒稍微长一些，是樟木做的，打开柜门的时候就闻到了一股樟脑的香气。箱子表面刷过清漆，边角磨得很亮，正面有一个铜做的锁扣，上面挂着一把小铜锁。

她试着掰了一下，锁很结实。

“青禾阿姨，这是什么？”

顾青禾正在擦桌子，回过头来看了一眼，手里的抹布停住了。

“这个……”她走过来，蹲下看了看，“我也不知道里面是什么。你爷爷一直放在这里，从来不让人动。”

“钥匙呢？”

“不知道。”顾青禾说，“我从来没见过钥匙。”

知遥把箱子翻过来看了看，箱底刻着两个字，刻得很浅，已经快磨平了，她凑近了才辨认出来：“同心”。

“同心？”她念出来。

顾青禾没有说话。她站起来，又回去擦桌子了。擦了两下，她说：“别撬它。你爷爷不喜欢别人撬他的东西。”

知遥本来也没打算撬。她把箱子放回柜子里，想了想，又拿出来，放到了楼上自己的房间里。

晚上，她给父亲打电话，说起这只箱子。

“什么箱子？”沈明川在电话那头说，“我不知道。你爷爷那些破烂，你看着办吧。”

“可能是很重要的东西。”

“能有什么重要的。”沈明川说，“要是存折或者房产证，早就放银行了。估计是他年轻时候的信，或者什么纪念品。你别管它了。”

挂了电话，知遥坐在床边看着那只箱子。月光从窗户照进来，落在箱子的铜锁上，亮亮的一小点。

她想起小时候，有一年夏天，她看见爷爷半夜一个人坐在柜台后面，面前就放着这只箱子。箱子是开着的，爷爷手里拿着一张纸，在灯下看了很久。她当时以为爷爷在算账，就没有出声，悄悄回楼上睡觉了。

那时候箱子是开着的，说明那时候有钥匙。

钥匙去哪里了？

许阿婆第二天一早就来敲门了。她在茶馆门口卖了二十多年的青团，三块钱一个，用竹叶垫着，放在一个大竹匾里。爷爷在的时候，许阿婆的摊子就摆在茶馆的屋檐下，下雨也淋不着。

“遥遥，阿婆的摊子还能摆在这里吗？”许阿婆问，有点不好意思。

“当然能。”知遥说。

许阿婆笑了，从竹匾里拿了两个青团塞给她：“趁热吃，豆沙的。”

知遥坐在门槛上吃青团。邻居家的黑猫煤球从墙头跳下来，在她脚边转了两圈，蹭了蹭她的裤腿，又跑开了。青溪的水在前面流着，对岸是一片新盖的楼房，白墙灰瓦，仿古的样式，窗户却是铝合金的。

顾青禾来开门的时候，看见她坐在门槛上，愣了一下。

“你还不回上海？”

“再待几天。”知遥说，“我想把爷爷的账本看一看。”

顾青禾点点头，进去烧水了。知遥听见她在里面把水壶放上炉子，然后很久没有动静。

她回头看了一眼，顾青禾站在柜台后面，手扶着柜台，看着那个空了的柜门，一动不动。
