# 第七章 约

程立第二次来的时候，带来了一份文件。

那天是星期三，茶馆里有七八个客人。程立没有坐，站在柜台前面，把文件夹打开，抽出一张纸，放在柜台上。

“沈小姐，有件事我想您应该知道。”他说，“我不太清楚沈先生有没有跟您说过。”

那是一份意向书。抬头写着“临水街房屋收购意向书”，甲方是青溪置业，乙方是沈明川。意向书写明，乙方同意将临水街一号房屋出售给甲方，价格八十万元，正式合同在房产手续办妥后签订。最下面是两个签名，一个是公司的章，一个是父亲的字。

日期是两个月前。

知遥看着那个日期，看了很久。两个月前，爷爷还活着。

“我们公司是按程序办事的。”程立说，语气还是很客气，“这份意向书没有法律上的强制力，不过沈先生是签了字的。我们希望能尽快把正式合同签下来。”

“我爸爸跟我说，他什么都没签。”

程立的笑容停了一下，然后说：“那可能是沈先生记错了。”

知遥把意向书推回去：“我会跟他谈。”

程立走了以后，她给父亲打电话。电话响了很久才接，父亲那边很吵，好像在饭桌上。

“意向书的事，你为什么骗我？”

电话那头安静了几秒钟。然后她听见椅子挪动的声音，脚步声，关门声。

“程立去找你了？”父亲的声音低下来。

“两个月前你就签了。爷爷那时候还活着。”

“我是跟你爷爷商量过的。”

“爷爷同意了吗？”

沈明川没有回答。

“他没同意。”知遥说，“你趁他还活着就去签字，他走了你又跟我说什么都没签。”

“遥遥，你听我说。”沈明川的声音有点急，“意向书不算数的，就是先表个态。那时候公司说，先签意向的人，价钱可以高一点。我是为了这个家……”

“为了这个家？”知遥打断他，“这个家你回来过几次？妈妈走了以后，你回来过几次？爷爷生病的时候，是谁陪着他？是青禾阿姨！”

她的声音很大，茶馆里的客人都转过头来看她。她拿着手机走到后院，站在那口被石板盖着的井旁边。

“你怎么知道我没回来？”沈明川说，“你在上海，你又回来过几次？”

知遥说不出话。

“遥遥，爸爸不是要跟你吵。”沈明川叹了口气，“这房子留着，以后谁住？你会回来吗？知南会回来吗？卖了，钱分给你们，你在上海买个房子，不好吗？”

“我不知道。”知遥说，“我现在不知道。”

她挂了电话，在井边站了很久。井口的石板上压着那盆葱，葱叶被太阳晒得有点蔫了。

她想起小时候，有一次父亲回来过年，和爷爷在楼下吵架。她和知南躲在楼梯上听，听不清他们在吵什么，只听见父亲说了一句：“这破茶馆能挣几个钱？”然后是摔门的声音。

那年父亲大年初二就走了。爷爷一个人坐在柜台后面，把那天的账记完，在边上写了一行字。她当时不认识那么多字，现在想起来，也许就是“明川走了”之类的话。

她又想起妈妈。妈妈是在杭州的医院里走的，那年她十六岁，在杭州读高中。妈妈病了一年多，父亲每天下了班就去医院，晚上睡在走廊的折叠床上。那一年父亲瘦了二十斤，头发白了一半。

妈妈走了以后，父亲就不怎么说话了。他把所有的时间都放在工作上，早出晚归，周末也加班。知遥高中住校，大学去了上海，毕业以后留在上海工作。她和父亲之间，好像隔了一条很宽的河，谁也不想先过去。

她不知道父亲签那份意向书的时候在想什么。也许他真的是为了这个家，也许他只是想把一件麻烦事早点了结。

她站在井边，把手放在那块青石板上。石板被太阳晒了一上午，摸上去暖暖的。

她想起爷爷说过，这口井以前是全街人吃水的地方。六十年代镇上通了自来水，这口井就没人用了，可是爷爷一直不肯填，只是盖上了石板。

“为什么不填？”她小时候问过。

“井是活的。”爷爷说，“填了，它就死了。盖着，它还在下面喘气。”

她当时觉得爷爷在讲故事。现在她把手放在石板上，好像真的能感觉到下面有一点凉气，慢慢地往上冒。

回到前面的时候，客人们都走了。顾青禾站在柜台后面，把那份意向书的复印件拿在手里，是程立留下的。

“你看了？”知遥问。

“看了。”顾青禾把复印件折起来，放在柜台上，“你爸爸是这样的人，一直都是。”

“青禾阿姨。”知遥在柜台前面坐下，“账本上每个月初九寄的两百块，到底是寄给谁的？”

顾青禾看着她，看了很久。外面的青溪水声哗哗的，收音机里在放天气预报，说下周可能有台风。

“是寄给我儿子的。”顾青禾终于说。

知遥愣住了。

“我儿子叫顾远，九一年考上大学，在省城读书。”顾青禾的声音很平，像在说别人的事，“我男人走得早，我一个人供不起。你爷爷说，学费和生活费他来出，每个月寄两百，一直寄到他毕业，后来又读研究生，一直寄到〇三年。”

“十三年。”

“十三年。”顾青禾说，“一百五十六个月，一个月都没少过。”

“爷爷为什么……”

“他说，那不是他给的，是我应得的。”顾青禾看着那根加固过的主梁，“他说茶馆每年赚的钱，有一半是我的。他不好直接给我，怕我不要，就寄给远远，算是我的那一份。”

“一半是你的？”知遥问，“为什么？”

顾青禾没有回答这个问题。她站起来，把茶壶里的剩茶倒掉，说：“远远现在在深圳，当工程师，过年会回来看我。你爷爷走的时候，他也回来了，你没认出来，站在灵堂最后面那个高个子就是他。”

知遥想起葬礼那天，确实有一个高个子的男人站在最后面，戴着眼镜，一直低着头。她以为是镇上哪家的亲戚。

“他给你爷爷磕了三个头。”顾青禾说，“磕得很响。”

那天晚上，知遥把账本上抄下来的那张纸拿出来，在每一个“初九 寄二百”后面，写上了两个字：顾远。

写到最后一个，二〇〇三年六月，后面那个小小的圆圈，她现在知道是什么意思了。那是爷爷画的句号。顾远毕业了，这件事做完了。

可是顾青禾说，茶馆每年赚的钱有一半是她的。

为什么是一半？

她又想起那张旧报纸上模糊的照片，穿白衬衫的年轻男人，扎着两条辫子的年轻女人。还有樟木箱子底下那两个字：同心。

她睡不着，下楼去倒水。茶馆里黑着，只有柜台上那台收音机的指示灯亮着一个小红点。她没开灯，摸黑走到柜台后面，在修好的藤椅上坐下。

藤椅很安静，一点声音都没有。陆砚说过，坐的人多了，手摸多了，藤条的颜色就会深下去，和原来一样。

她把手放在扶手上，来回摸了几下。

窗外下起了小雨，雨点打在门板上，沙沙的。她想起爷爷说过，这间房子下雨天会叹气。她仔细听了听，只听见雨声，还有墙上那只挂钟的嘀嗒声。

挂钟敲了一下，一点了。

她拿起手机，翻到通讯录里父亲的名字，看了很久，最后没有打出去。她给他发了一条消息：“我说话太冲了。可是意向书的事，你还是错了。”

消息发出去，很快就显示已读。过了几分钟，父亲回了一个字：“嗯。”

又过了一会儿，父亲又发来一句：“早点睡。”

她把手机放下，在藤椅上又坐了一会儿，然后上楼了。

第二天早上，她给赵德明打了个电话。赵德明耳朵背，她说了三遍，他才听明白。

“箱子的钥匙？”赵德明在电话那头说，“你等着，我明天给你送去。”

“您有钥匙？”

“有。”赵德明说，“你爷爷说，等你回来了，等你问了，再给你。”
