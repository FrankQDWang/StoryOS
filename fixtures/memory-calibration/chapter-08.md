# 第八章 钥

赵德明第二天上午就来了，是陆小满骑自行车带他来的。

老人坐在红色自行车的后座上，一手抓着车座，一手拄着拐杖，在石板路上颠得厉害。陆小满一边骑一边喊：“赵爷爷你抓紧！别松手！”整条街的人都探出头来看。

到了茶馆门口，陆小满把车停稳，扶着赵德明下来，喘着气说：“姐，赵爷爷非要今天来，说一天都不能等。我哥不让他坐电动车，怕他摔着。”

“那你就让他坐自行车？”

“自行车慢呀。”陆小满理直气壮地说。

赵德明在靠窗那张桌子边坐下，从怀里掏出一个手帕包，一层一层打开，里面是一把小小的铜钥匙，钥匙柄上拴着一根褪了色的红绳。

“三年前，你爷爷把这个交给我。”赵德明说，“那时候他已经知道自己身体不好了。他说，老赵，这个你帮我收着。等遥遥回来，等她自己问起这个箱子，你再给她。她要是不问，你就带到棺材里去。”

“为什么要等我问？”

“他说，你要是不问，就说明你不在乎这个茶馆。那就不用知道了。”

知遥接过钥匙，钥匙被手帕捂得温温的。

她上楼把樟木箱子抱下来，放在桌上。顾青禾从柜台后面走过来，站在旁边，没有说话。陆小满凑过来想看，被赵德明用拐杖轻轻拦住了。

钥匙插进锁孔，转了一下，“咔哒”一声，锁开了。

箱子里的东西不多，整整齐齐地放着。最上面是一叠信，用一根蓝色的布条捆着，大约有二三十封。信下面是一个牛皮纸的信封，封口没有粘。最底下是一块红布，包着一样小东西。

知遥先打开了牛皮纸信封。

里面是三张纸。第一张是一九八三年的房屋买卖凭证，房管所盖的章，买方写着沈怀山，房屋地址是临水街一号，价格是四千二百元。

第二张是一张收条，手写的，字很工整：“今收到顾青禾交来购房款贰仟壹佰元整，系临水街一号房屋价款之半数。此房屋为沈怀山、顾青禾二人共有，各占一半。日后如有变卖，须经二人同意。”下面是两个签名，沈怀山，顾青禾，还有两个红手印。最下面写着：“见证人：赵德明”。

第三张是同一份内容的另一张，日期是二〇一九年，字迹已经歪了，是爷爷后来重新写的。末尾多了一行：“此据经镇司法所公证。”后面附着一张公证书的复印件。

知遥把这三张纸看了两遍，抬起头。

顾青禾站在那里，眼睛红了，可是没有哭。

“一半是你的。”知遥说。

“七九年开茶馆的时候，你爷爷一个人撑不起来，我就过来帮忙。”顾青禾的声音很轻，“那时候我男人刚走，我一个人带着远远，你爷爷给我开工钱，让我有口饭吃。八三年房管所要卖房子，你爷爷钱不够，我把我男人留下的抚恤金全拿出来了，两千一百块。”

“那时候不能写两个人的名字？”

“那时候不兴这个。”赵德明在旁边说，“一个寡妇，一个鳏夫，房子写在一起，镇上的人要说闲话的。怀山就写了这个条子，叫我做见证。”

“二〇一九年那张呢？”

“那年你爸爸第一次说要卖房子。”顾青禾说，“你爷爷怕他走了以后，这张老条子不算数，就去镇上做了公证。”

知遥低头看着那张公证书。公证的日期是二〇一九年十一月。

“所以，”她慢慢地说，“没有你同意，这房子卖不了。”

“卖不了。”赵德明说，“谁签什么意向书都没用。”

知遥打开了那叠信。信是爷爷写的，一封一封都没有寄出去，收信人都是同一个人：青禾。最早的一封是一九八〇年，最晚的一封是今年二月。她只看了第一封的开头，就把信放下了。

“这些是写给你的。”她把信递给顾青禾。

顾青禾接过信，抱在怀里，转过身去，走到后院去了。

最后，知遥打开了那块红布。里面是一枚铜做的小印章，印面刻着两个字，和箱底的字一样：同心。

“这是茶馆的章。”赵德明说，“七九年开张的时候刻的，怀山一枚，青禾一枚。青禾那枚，八几年的时候掉到河里去了。”

陆小满一直在旁边看着，这时候小声问：“赵爷爷，他们两个……是一对吗？”

赵德明敲了敲烟斗，过了很久才说：“他们是一起开茶馆的人。”

中午，陆小满不肯走，非要留下来吃饭。知遥煮了一锅面条，赵德明吃了小半碗，说老了，吃不动。陆小满吃了两大碗，一边吃一边说她们学校食堂的面条是全世界最难吃的。

“你哥呢？”知遥问，“他不来吃饭？”

“他在祠堂干活，中午不回来。”陆小满说，“他从来不按时吃饭，我说了他也不听。”

“那你晚上给他带点回去。”

“好呀。”陆小满眼睛一转，“姐，你是不是对我哥有意思？”

赵德明在旁边咳嗽了一声，烟斗差点掉了。

“吃你的面。”知遥说。

陆小满嘿嘿笑着，低头吃面，吃了两口又抬起头：“我哥这个人，什么都不说，可是心里有数。他给你修那把藤椅，修了整整三个晚上，编藤条编到手都破了。他给别人修东西，从来不这样。”

知遥没有接话，把一碟咸菜推到她面前。

吃完饭，赵德明要回去睡午觉。陆小满扶着他出门，又让他坐上自行车的后座。赵德明临走前，回头看了一眼茶馆，看了一眼那块招牌。

“遥遥。”他说，“你爷爷这辈子，就两件事放不下。一件是这个茶馆，一件是青禾。现在两件事，都交给你了。”

陆小满骑着车，载着赵德明慢慢走远了。红色的自行车在石板路上一颠一颠的，赵德明的拐杖横在车后座上，像一根扁担。

知遥回到桌子边，又把那张一九七九年的旧报纸拿出来，和收条放在一起。照片上那个扎着两条辫子的年轻女人，站在穿白衬衫的男人旁边，笑得很开心。

她现在知道这个女人是谁了。

她拿着报纸去后院，顾青禾还坐在井边。知遥把照片指给她看。

顾青禾看了很久，伸手摸了摸照片上那个模糊的人影。

“那天我穿的是一件红格子的衬衫。”她说，“照片是黑白的，看不出来。”

“你那时候多大？”

“二十九。”顾青禾说，“你爷爷三十一。镇上照相馆的小刘来拍的，拍完了说要登报，我们俩都不信，以为他吹牛。结果真登了。”

她把报纸还给知遥，又说：“他那天穿的白衬衫，是借赵德明的。他自己没有白衬衫。”

下午，知遥给父亲打了电话，把收条和公证书的事情告诉了他。

电话那头沉默了很久。

“我不知道。”沈明川说，声音很哑，“你爷爷从来没跟我说过。”

“他跟你说了，你会听吗？”

沈明川没有回答。过了一会儿，他说：“程立那边，我去说。”

挂了电话，知遥走到后院。顾青禾坐在那口盖着石板的井边上，手里拿着一封信，已经看完了，信纸摊在膝盖上。

“青禾阿姨。”

“他写字一直这么丑。”顾青禾说，抹了一下眼睛，“写了四十年，一点长进都没有。”

知遥在她旁边坐下。春天的风从青溪上吹过来，吹得那盆葱轻轻摇晃。

“这房子，你想卖吗？”知遥问。

顾青禾把信纸折好，放回信封里。

“不卖。”她说，“这是他和我一起开起来的。”
