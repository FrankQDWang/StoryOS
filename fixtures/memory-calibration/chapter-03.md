# 第三章 账

爷爷的账本有十一本，整整齐齐码在楼上衣柜的顶层，用一块旧床单盖着。

知遥搬了一张凳子，踩上去一本一本拿下来。账本都是一样的样子，蓝色的布面，硬纸板做的封皮，书脊用白线缝过好几遍。最早的一本封面上写着“一九八九”，最晚的一本没有写年份，翻开来，最后一笔记的是今年三月：“茶叶，二斤，一百六十元”。

字是爷爷的字，越往后越歪，到最后几页，有的数字要看半天才认得出来。

她把账本搬到楼下，摊在靠窗那张桌子上。顾青禾在柜台后面择菜，看了一眼，没说话。

账本记得很细。每天卖了多少碗茶，进了多少斤茶叶，交了多少电费，给谁赊了账，谁又还了，都记着。有些页的边上还有几行小字，不是账目，像是随手记下的事情：“今日大雨，客三人”“明川来信，要钱”“遥遥会背唐诗了”。

她看到这一行的时候停了很久。那是二〇〇三年的夏天，她五岁。

她往后翻，翻到一九九一年，发现了一件奇怪的事情。

每个月的初九，账本上都有一笔支出，写着“初九 寄二百”。没有写寄给谁，也没有写是什么钱，就是这几个字，每个月一次，从不间断。

她拿起另一本，一九九五年，还是有。一九九八年，有。二〇〇二年，有。一直到二〇〇三年的六月，最后一笔“初九 寄二百”，后面画了一个小小的圆圈。从七月开始，再也没有了。

十三年，每个月两百块。她在手机上算了算，一共三万多。九十年代的两百块不是小数目，茶馆那时候一碗茶才卖五毛钱。

“青禾阿姨。”她抬起头，“爷爷每个月初九寄钱，你知道是寄给谁的吗？”

顾青禾择菜的手停了一下，又接着择。

“不知道。”她说，“你爷爷的事，他不说，我也不问。”

知遥看着她。顾青禾低着头，把一根芹菜的叶子一片一片摘下来，摘得很慢。

她没有再问。

快到中午的时候，有人来敲门。

门口站着一个三十多岁的男人，穿一件深灰色的西装，没有打领带，手里拿着一个黑色的文件夹。他的头发剪得很短，脸上带着笑，看起来很客气。

“请问是沈知遥小姐吗？”

“我是。”

“您好，我叫程立，是青溪置业的。”他递过来一张名片，“沈先生应该跟您提过我们公司。”

知遥接过名片看了一眼，名片很厚，烫着金色的字。她抬头的时候，看见他手腕上戴着一块银色的表，表盘很大，在阳光下一闪一闪。

“我爸爸提过，有公司要收购。”

“对，就是我们。”程立笑着说，“方便进去聊几句吗？不会耽误您太久。”

知遥让他进来了。顾青禾从柜台后面看了程立一眼，转身进了后屋。

程立在靠窗的桌子边坐下，看见桌上摊开的账本，笑了一下：“老人家记账很仔细啊。”

知遥把账本合上，放到一边。

“沈小姐，我就直说了。”程立打开文件夹，拿出几张纸，“临水街整条街我们都在谈，已经签了十一户。这条街要做成文旅街区，保留外立面，里面全部重新做，以后会有民宿、咖啡馆、文创店。”

他把一张效果图推过来。图上的临水街干干净净，石板路换成了新的，两边的房子都挂着灯笼，河边有一排木头长椅，几个年轻人坐在上面拍照。

知遥看着那张图，图上的临水茶馆还在，招牌也还在，只是门口多了一块牌子，写着英文：TEA HOUSE。

“这间茶馆，我们的报价是八十万。”程立说，“这个价钱在青溪镇是很高的。您可以去问问，镇上新盖的商品房，一百平米也就六七十万。”

“八十万。”知遥重复了一遍。

“对。”程立说，“而且我们可以一次付清，手续都由我们来办，您不用操心。”

知遥没有说话。她看着窗外，青溪的水很平，有一只白鹭站在对岸的石头上，一动不动。

“我爸爸怎么说？”

程立顿了一下，笑容没有变：“沈先生的意思是，这件事要跟您商量。他说您是长孙女，老人家生前最疼您。”

“那我想一想。”

“当然，当然。”程立把文件收起来，只留下那张效果图，“您慢慢考虑。不过我也要跟您说实话，这条街的项目时间比较紧，公司希望年底之前能把所有的户都谈下来。”

他站起来，又看了一眼茶馆，目光在柜台后面那把藤椅上停了一下。

“老房子很有味道。”他说，“我们会好好保护的。”

他走了以后，知遥坐在那里很久没有动。

顾青禾从后屋出来，手里端着一碗面，放在她面前。是阳春面，上面撒着葱花。

“吃吧。”

“青禾阿姨，你觉得应该卖吗？”

顾青禾在她对面坐下，看着那张效果图，看了很久。

“这是你们沈家的房子。”她说，“我说了不算。”

“我想听你说。”

顾青禾摇了摇头，没有回答。她站起来，把效果图翻过来，扣在桌面上，然后回柜台后面去了。

吃完面，知遥出去走了走。

临水街不长，从茶馆走到街口，慢慢走也就十分钟。她第一天来的时候下着雨，没有看清楚，现在才发现，街上有好几户人家的门上都贴着那种红色的通知。她走近了看，通知是青溪置业印的，上面写着“本户已签订收购协议，感谢支持临水街改造”，下面盖着公司的章。

她数了数，一共十一户，和程立说的一样。

第五户是以前卖酱油的老王家。门开着，里面空了一半，地上堆着纸箱子。老王的儿子正在往一辆小货车上搬东西，看见她，停下来打了个招呼。

“你是沈爷爷的孙女吧？”

“是。你们要搬了？”

“下个月搬。”老王的儿子擦了擦汗，“我爸去年走了，房子空着，我在县城上班，也不回来住。公司给的价钱还行，就签了。”

“你舍得吗？”

他愣了一下，然后笑了：“有什么舍不得的。房子老了，一下雨就漏，修一次好几千。卖了，在县城给孩子买个学区房，比放在这里强。”

知遥点点头。他说的都对，她想不出什么话来反驳。

再往前走，是一家关了门的理发店，玻璃门上还贴着一张褪色的价目表：剪发五元，洗头三元，刮脸两元。理发店隔壁是一个小小的土地庙，只有半人高，里面供着一尊石头的小像，像前面摆着两个苹果，已经有点干了。

街口有一棵老槐树，树下坐着几个老人在下象棋。他们看见知遥，有一个抬起头说：“怀山的孙女回来了？茶馆还开吗？”

“还没想好。”

“开吧。”那个老人说，“没有茶馆，我们下完棋都没地方喝茶了。”

旁边的老人敲了敲棋盘：“该你走了，别说话。”

知遥站在树下看他们下了一盘棋。走马、跳炮、将军，一盘棋下了半个钟头，最后是和棋。两个老人都不服气，又摆了一盘。

她往回走的时候，太阳已经偏西了。青溪的水被照得金黄，老桥的影子落在水面上，长长的一条。

下午，知遥继续看账本。她把每个月的“初九 寄二百”都抄在一张纸上，一共一百五十六笔，从一九九一年一月到二〇〇三年六月，一个月都没有漏。

她把这张纸夹在最后一本账本里。

傍晚，周晚晴打来电话。周晚晴是她小学同学，以前住在临水街的另一头，现在在镇上的小学当老师。

“听说你回来了？”周晚晴的声音还是和小时候一样，很亮，“怎么不找我？”

“刚办完葬礼，还没顾上。”

“这几天学校忙，过了这阵我去茶馆看你。”周晚晴说，“你可别又一声不响走了。”

“不会。”

“你小时候也是这么说的。”周晚晴笑了。

挂了电话，天已经黑了。知遥把账本收好，关了灯，坐在黑暗里。窗外的青溪映着对岸新楼的灯光，一闪一闪的。

八十万。

她在上海的房租一个月六千。八十万，够她付十一年的房租。

她想起账本边上那一行小字：“遥遥会背唐诗了”。爷爷记这一行的时候，用的是什么样的心情呢？
